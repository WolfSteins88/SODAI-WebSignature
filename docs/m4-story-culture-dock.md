## Content and routing

`storyPanels` is an ordered bounded array of fixed layout types, stable IDs, enabled flags, copy and image references. The `culture` collection has its own enabled flag, hero, introduction, ordered entries, stable IDs and published detail fields. Schema validation rejects duplicate IDs/slugs and arbitrary image URLs. Existing scoped JSONB draft, published and revision snapshots gain two legacy Story panels through `drizzle/0001_signature_collections.sql`, each derived from its own copy and images; existing Culture remains disabled. Fresh fictional seed data has nine Story panels and ten Culture entries. There is no browser-side content fallback. The M5 editor can edit and reorder these fields through the existing validated save/publish operation.

Signature-only Culture URLs, canonical metadata and sitemap entries follow the enabled published collection. Disabled Culture and entry detail routes return 404. Standard public routes are unchanged. `/story` continues redirecting to the canonical Signature root. The menu shows Culture only when published and enabled. The page transition prefetches its destination and image before the handoff.

## Remaining differences and limits

The demo uses original fictional villa copy, a Sodai wordmark, system fonts and eight licensed illustrative photographs. It does not have Tandjung Sari's exact images, historical account, proprietary typeface, video, or photographic sequence, so pixel identity is not claimed. Original cultural copy is intentionally concise and should be reviewed with local subject experts before a real villa launch. Reference timing is inferred from sampled recordings; exact easing and scroll deltas cannot be measured from them. The browser control surface does not expose a touch device or an OS reduced-motion preference toggle, so those code paths are implemented but not physically verified here. No authenticated Netlify Database/Blobs context was supplied; live hosted integration remains unverified. The separately documented M1 TOTP/login UI and CLI setup gaps remain outside this M4 revision. M5 editor and M6 deployment/ZIP work were not started.
